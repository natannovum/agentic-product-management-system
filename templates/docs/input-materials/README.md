# Input Materials

User-supplied briefs, references, source files, exports, and anything handed over as raw input to work from.

**Kept because provenance matters.** When a decision traces back to "the brief said so", the brief needs to still exist and be readable in the state it was given.

**Not a scratch directory.** Working files belong in a temporary location; this is for inputs worth preserving.

**Never place credentials here**, in any form, including inside an export or a screenshot. See `CLAUDE.md` → Secret Handling.
